# MGIS130-D2
GPA CALC
What Information goes in? - The grades of the person for whatever term they want to calculate their GPA for or all of the semesters they have taken to get a total GPA.
What do you do with it? - Calculate their GPA based on the letter grades they give us so it should calculate a number based off of a letter grade (A,B,C,A-) that they give us and then we transfer those letters to numbers and calculate an average.
How should it look? - It should look simple and easy to understand where they should put each letter and a selection of what course they got that letter grade in. It should also be clear what percent is which letter grade and how they can edit that. An app that does this is "GPA calculator" on the app store it is simple and it has a very clean user interface and it has all of the items I listed above.
